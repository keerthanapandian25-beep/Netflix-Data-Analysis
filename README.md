# Netflix Data Analysis

## Project Overview

This project analyzes a Netflix dataset using Python to understand content types, release years, ratings, countries, and duration.

## Tools & Technologies

- Python
- Pandas
- NumPy

## Dataset

The dataset contains 100 Netflix titles with information such as:

- Show ID
- Title
- Type
- Release Year
- Rating
- Duration
- Country
- Date Added

## Analysis Performed

- Checked dataset shape and columns
- Checked missing values
- Analyzed Movies vs TV Shows
- Analyzed content by release year
- Analyzed ratings
- Analyzed countries
- Analyzed movie duration
- Analyzed TV Show seasons
- Compared country and content type

## Project Files

- `netflix_analysis.py` – Python analysis code
- `netflix_data_100-1.csv` – Dataset
- `Netflix_project_report.txt` – Project report

## Conclusion

This project demonstrates basic data analysis using Python, Pandas, and NumPy and provides insights into Netflix content.
